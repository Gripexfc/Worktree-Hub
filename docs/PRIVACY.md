# 隐私说明

Worktree Hub 采用本地优先设计。

## 工具读取的数据

用户选择目录后，工具会在本机读取用于展示和管理 worktree 所需的信息，包括：

- 目录路径和仓库名称
- Git worktree、分支和本地 refs
- 最近提交的摘要与时间
- 已修改、未跟踪、锁定或失效状态
- 项目中已有的构建脚本及预览产物位置

## 工具不会做的事情

- 不提供账号系统，不要求登录
- 不包含遥测、分析 SDK、广告 SDK 或崩溃上报服务
- 不把仓库信息、文件路径、分支、提交或配置上传到服务器
- 扫描阶段不执行 Git 网络操作；“合并到测试”流程仅在用户明确确认后执行提交、推送、同步和合并，且会在窗口中展示每一步操作日志
- 不自动读取或复制 `.env`、SSH 密钥、访问令牌和其他凭据

## 本地存储

macOS 应用把扫描目录、编辑器偏好和项目级主/测试分支规则保存在：

```text
~/Library/Application Support/Worktree Hub/config.json
```

Windows 安装版保存在 `%LOCALAPPDATA%\Worktree Hub\config.json`。直接运行源码时，配置默认保存在项目目录的 `.data/config.json`。删除这些文件即可清除 Worktree Hub 保存的设置。

## 本地服务

界面服务默认只监听 `127.0.0.1`。修改请求需要进程启动时随机生成的令牌，该令牌只存在于当前进程和本地页面中。

## 用户主动启动的外部程序

点击编辑器、Web 预览或微信开发者工具后，Worktree Hub 会启动用户本机安装的软件或仓库已有脚本。第三方软件、包管理器和项目脚本可能根据各自配置访问网络；Worktree Hub 无法替它们提供隐私保证。

如果需要审计，可在离线环境运行 Worktree Hub，并在使用预览功能前检查目标仓库的脚本。
